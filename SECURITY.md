# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or credential handling issue, please do NOT open a public GitHub issue.

Please report vulnerabilities directly via:
- **Telegram:** [Arbitrage Inception Telegram](https://t.me/ArbitrageInception)

### Guidelines
- Never commit active API keys (`HELIUS_API_KEY`, `BIRDEYE_API_KEY`, `PYTH_API_KEY`) to version control.
- Ensure all queries use parameterized database statements.
