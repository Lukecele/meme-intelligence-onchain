# Contributing to Solana Meme Intelligence Baseline

We welcome open-source contributions to enhance Solana wallet clustering, first-buyer attribution, and real-time mempool telemetry.

## How to Contribute
1. Fork the repository.
2. Create a feature branch: `git checkout -b feat/your-feature`.
3. Verify compilation: `python -m compileall -q .`.
4. Ensure no hardcoded credentials or synthetic datasets are introduced into productive pipelines.
5. Submit a Pull Request with a clear rationale.
